# ExeBlueprint v0.3.0

這一版重新安排桌面操作流程，加入 Windows 安裝程式與 macOS DMG，也收錄 v0.2.1 之後的 .NET、資源與原生呼叫分析更新。

## 桌面操作

- 依「選來源、設定輸出、開始分析」操作，進度、結果摘要與注意事項集中在右側，其他語言和 Ghidra 設定收進進階選項。
- 可拖入檔案或資料夾，保留最近成功分析的八個來源，也能直接貼上檔案總管複製的帶引號路徑。
- 分析與資料夾掃描在背景執行，期間可取消；關閉視窗會先取消工作，等待清理完成再退出。
- 使用預設位置再次分析時會另建結果資料夾；自訂位置已有報告時仍須明確允許覆寫。
- 隨附 Noto Sans TC 字型，改善 Linux 沒有中文字型時的缺字問題；支援小視窗、鍵盤操作與 150% 縮放。

介面與操作步驟見[桌面版說明](https://github.com/NickYCLin/exe-blueprint/blob/v0.3.0/docs/desktop-guide.md)。

## 分析與輸出

- 可展開 Electron ASAR，保留檔案來源；修正 .NET apphost 對應組件的解析。
- 讀取 `.resources` 標準鍵值、預序列化資源封裝，以及 PNG／GIF 檔頭尺寸；摘要不會執行型別轉換器或反序列化物件。
- 增加 WPF BAML 型別、屬性、元素樹與資源關係摘要，並整理內嵌 JSON／XML 設定的欄位結構，省略設定值。
- C# 輸出補上泛型變異與約束、delegate、indexer、函式指標、可確認的建構子初始化及更多分支與整數運算；加強 IL 與 metadata 驗證，無法確認語意時保留 IL 與未還原註記。
- Ghidra 分析增加靜態 CALL 呼叫圖與無條件直接 tail call，並保留匯出失敗原因。Ghidra 12.1.3 需安裝官方隨附的 Jython 擴充，設定見[原生分析說明](https://github.com/NickYCLin/exe-blueprint/blob/v0.3.0/docs/native-acceptance.md)。
- `blueprint.json` 的 `schemaVersion` 為 `0.19`。讀取結果的腳本應檢查版本及各層不完整狀態，欄位定義見[架構說明](https://github.com/NickYCLin/exe-blueprint/blob/v0.3.0/docs/architecture.md)。

## 使用範圍與限制

- 主要分析對象仍是 Windows EXE、DLL 與應用程式套件；工具在 macOS／Linux 執行不代表支援還原這些平台的原生程式。
- 分析不會執行輸入程式。設定欄位摘要會省略值，但其他資源或 IL 仍可能包含原始字串，分享報告前請自行檢查。
- PNG／GIF 摘要只讀取檔頭，並非完整圖片驗證；BAML 摘要也不等於完整還原 UI。
- C# 骨架不保證直接編譯；C++／Rust／Go 目前只提供型別與方法簽章。條件／間接 tail call 與原生方法體還原仍未支援。
- Windows 產物沒有程式碼簽章；macOS 沒有 Apple Developer 簽章與公證。安裝程式或 DMG 不會消除系統的首次開啟提醒。
- Linux 桌面版需要 X11 或 XWayland，以及 `libx11-6`、`libice6`、`libsm6`、`libfontconfig1`。
- 發佈流程會驗證 Windows 安裝、模擬升級與移除，以及兩種 Mac 架構的 DMG 掛載、CLI 版本和檔案複製；不代表已驗證所有使用者環境或 macOS Gatekeeper 首次開啟。

English: Redesigned desktop workflow, Windows installer and macOS DMGs, expanded .NET/resource analysis, and native call graphs with direct tail calls. Packages include the .NET runtime. Windows binaries are unsigned; macOS packages have no Apple Developer signing or notarization.
